## Selected Work

| Project | What it does | Role | Stack |
|---|---|---|---|
| **[monitr](https://monitr.xyz)** · live | Puts world events on a live globe as they happen, sorted into panels for conflict, trade, climate, sports, cybersecurity, elections, health, space news, and maritime chokepoints | Co-founder & Head Developer | React, Node, GDELT/OSINT feeds |
| **[PhyLabeler](https://github.com/zawmbi/phylabeler)** | Labels phylogenetic trees and checks each clade for monophyly. Runs against 2.9M NCBI taxon references and flags conflicting tips for review | Solo developer | Python, Biopython, ETE3 |
| **[MissMap](https://github.com/zawmbi/MissMap)** | Audits how much sequence data exists for plant taxa across NCBI, using AI-proposed, taxonomy-validated synonyms to catch records hidden under alternate names | Solo developer | Pandas, Biopython, NCBI, LLMs |
| **Archiveum** · private | A tool similar to Modash for select clients · [archiveum.xyz](https://archiveum.xyz) | Co-founder & Head Developer | React, Node, graph data |
| **[Lightning Auto Plus](https://lightningautoplus.com)** | The live site for my local auto shop | Solo developer (passion project) | Web |

<sub>monitr and Archiveum are closed-source, but I'm happy to walk through the code on request.</sub>
